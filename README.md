# First Hibernate Demo 🚀

A beginner-friendly Hibernate project created to understand the fundamentals of **Hibernate ORM** and how Java applications interact with a relational database.

## 📌 About the Project

This project demonstrates the basic implementation of Hibernate with Java and MySQL.

Hibernate is an **Object-Relational Mapping (ORM)** framework that allows Java objects to be mapped to database tables.

Instead of writing SQL queries for every database operation, Hibernate allows us to work with Java objects.

## 🛠️ Technologies Used

- Java
- Hibernate ORM
- Maven
- MySQL
- Eclipse IDE
- JDBC
- Git & GitHub
